================================================================================
  PACKAGE_MAP — 패키지 배치 SSOT
================================================================================

□ 역할
- IDE 탐색·신규 클래스 배치의 단일 기준.
- PROJECT_PLAN 절 8 feature 루트(uds.io, uds.catalog, …)는 유지하고,
  하위를 역할(role) 단위로만 나눈다.
- Step 프롬프트·IMPLEMENTATION_SLICES 클래스 목록은 이 파일 경로를 따른다.

□ 원칙
1. 깊이 상한: uds.<feature>.<role>  (GUI만 uds.gui.<feature>)
2. 클래스 수 ≤4 인 feature는 평탄 허용 (현재: uds.io)
3. 새 클래스는 아래 표의 역할 패키지에만 추가. 평탄 feature 루트에 직접 추가 금지
4. No Look-Ahead: 미착수 feature 루트뿐 아니라, 같은 feature의 미착수 role
   빈 껍데기 패키지/클래스도 만들지 않는다
5. Apache POI (Workbook/Sheet/Row/Cell)는 uds.catalog.load.CatalogLoader 내부만
6. 테스트는 src/test/java 에서 동일 패키지 경로를 미러한다
7. FQCN 이동 시 동작·테스트 기대값 변경 금지 (패키지·import만)
