□ 공정 규칙 (Stop-the-Line)
- Hard Gate: 지정 mvn test Failures:0 Errors:0 전 다음 Step 금지

- Excel/CSV SSOT는 POI 또는 Python으로 실파일 읽어 어설션 (채팅 요약 금지)

- 절대 제약: POI=CatalogLoader만 / ActiveDiagnosticContext 단일 쓰기 /
  Guard→Coordinator→Policy→Recording→File / 0x27 완전 격리 /
  BigDecimal 표시 자릿수=scale / CSV expected_status 1:1

□ 목표 계층
- 1차 (Slice 1~4 / Step 1A~4B): unlock→RD-VESC-001 GUI 완주
- 2차 (Slice 5~8 / Step 5~8): Write / Session / AI / 전수 회귀

3. Cursor 프롬프트 위치 (장문은 여기 두지 않음)
================================================================================
- docs/prompts/steps/CURRENT.txt …… 지금 Step ID (DONE = Micro-Gate 종료)
- docs/prompts/steps/STEP_*.txt …… 해당 Step 전문
- docs/prompts/steps/STOP_RECOVERY.txt …… 실패 시
- docs/prompts/steps/README.txt …… @ 사용법
- docs/UX_USABILITY_BACKLOG.txt …… DONE 이후 UX 후속 SSOT
세션마다 CURRENT가 가리키는 STEP 파일 하나만 붙인다.
CURRENT=DONE 이면 UX 작업 시 UX_USABILITY_BACKLOG + PACKAGE_MAP만 붙인다.
