5. Open questions — 코드 사실 답
================================================================================

Q1. UX-01/03 바인딩 교체 위치?
A1. uds.gui.app.UdsGuiApplication
      - readTab(): 「Refresh DIDs from profile」 Button setOnAction
      - writeTab(): 「Refresh Write DIDs」 Button setOnAction
      - aiTab(): PauseTransition(200ms) 폴링
    uds.gui.shell.MainViewModel.selectProfile(String)
      - access/read/write/analysis/ai 에 onProfileChanged 전파(이미 있음)
      - 뷰 ComboBox items는 아직 VM Observable에 미바인딩 → UX-01 대상

Q2. UiTaskRunner 형태?
A2. java.util.concurrent.CompletableFuture + ExecutorService + cancel/orTimeout(15s).
    javafx.concurrent.Task 래핑 아님. FX 마샬은 Platform.runLater(툴킷 없으면 inline).
    → runningProperty/progressProperty/onSucceeded 확장이 맞는 방향.

Q3. FixtureRunConfig 공유?
A3. AppSession이 FileDiagnosticExchangePort·Simulator·Recording 단일 인스턴스.
    Read/Write 탭 각각의 scenario ComboBox는 facade.setFixtureRunConfig(id)로
    동일 Port 설정을 덮어쓴다. 탭 전용 Port를 만들면 안 된다.
