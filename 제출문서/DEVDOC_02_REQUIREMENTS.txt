1. 문제와 사용자
--------------------------------------------------------------------------------

한 줄
  JavaFX에서 UDS HEX를 해석하고, Excel 프로필 기준 Extended·SecurityAccess 후
  교육용 Read/Write를 수행하며, 관측 사실을 외부 AI가 설명한다.

누가
  JAVA 수업 시연자, 자작자동차 동아리 임베디드 팀원

해결할 문제
  · HEX 로그만으로는 세션·보안·DID 의미를 수업/벤치에서 빠르게 설명하기 어렵다.
  · 실차 CAN 없이 Extended·Unlock·Read/Write·AI 흐름을 재현·검증할 도구가 필요하다.
  · seed/key·비밀번호가 로그·AI로 새면 안 된다.

기대 개선
  · Offline Simulation(File ECU)만으로 UC 핵심 흐름 시연
  · Interpreter 사실 구역과 AI 설명 구역 분리
  · live_session.log / .session JSONL로 교환 추적


--------------------------------------------------------------------------------
2. 대표 사용 시나리오
--------------------------------------------------------------------------------
(상황 / 사용자 행동 / 기대결과)

[S1] 실거래 로그 해석 (UC-01)
  상황   TEST=TRUE로 GUI 실행, 이번 세션에서 Access 등을 이미 수행함
  행동   Interpreter 탭 → 「이번 세션 로그」 (또는 탭 선택 시 자동 갱신)
  기대   ts,direction,hex 프레임이 SID/서비스/필드 표로 표시.
         Log level Normal이면 TesterPresent(0x3E) 숨김, Verbose면 표시.
         줄 오류는 ERR 행으로 분리. AI 탭과 시각적으로 분리.

[S2] Extended Session · 비밀번호 인증 (UC-06)
  상황   Target ECU = FARDRIVER_ND72530 또는 FLIPSKY_75100_VESC, 아직 DEFAULT
  행동   Session Control = Extended Session → Apply → 비밀번호 입력
  성공   10 03 / 50 03 → 27 01 / 67 01 → 27 02 / 67 02 → EXTENDED_UNLOCKED
         live_session.log에 해당 HEX 기록, 0x27 payload는 마스킹
         Extended 유지 중 TesterPresent(3E 80) 주기 송신 시작
  실패   잘못된 비밀번호 → 7F 27 35(INVALID_KEY) 후 DEFAULT로 롤백
         10 01 / 50 01 복귀 로그, keep-alive 중지, Read/Write 불가

[S3] 모터 급정지 현상 → Read → AI (UC-02)
  상황   「모터가 갑자기 멈췄다」 원인 확인 필요
  선행   S2로 EXTENDED_UNLOCKED (예: Flipsky)
  행동   AI Advisor에 현상 입력 → SymptomDidMap 후보 확인
         ReadData에서 DID(예: 0x1001) · 시나리오 RD-VESC-001 실행
         AI 설명 요청
  기대   예: 50.0 V · ABNORMAL Finding(결정론) + AI 설명(사실 구역과 분리)
         locked 상태면 ACCESS_DENIED, Port 호출·JSONL 요청 0건

[S4] WriteData → 결과 (UC-05)
  상황   교육용 writable DID 값 변경 시연
  선행   S2 unlock
  행동   WriteData 탭에서 DID·값 입력 → 실행
  기대   0x2E / 0x6E → ACCEPTED 등(CSV expected_status 1:1)
         범위·타입 오류는 Port 호출 없이 VALIDATION_ERROR_*
         실제 모터/ECU 상태 변경 없음

3. 범위와 우선순위
--------------------------------------------------------------------------------

Must (없으면 시연 불가)
  Interpreter 사실 해석, Excel 프로필·DID 선택, Extended+Unlock,
  Guarded Read/Write, File ECU 교환·기록, AI 설명(민감정보 제거),
  장비 없이 UC-01/02/04/05/06 완주

Should / 후속 (이번 제출에서 약화·생략 가능)
  UC-03 팀 폴더 복원 UI, 레퍼런스 로그 파일 열기 UI, 실제 Socket/CAN,
  OEM 실키 알고리즘, ISO-TP 재조립

제외
  실차 액추에이터 제어, 팀 문서 RAG, CAN 하드웨어 필수 시연

5. 완료기준 (Acceptance Criteria)
--------------------------------------------------------------------------------
형식: 시작상태 → 행동 → 기대결과  (9주차 AC 예시와 동일)

AC-UC-01  실거래 해석
  시작  output/live_session.log에 Access 교환이 있음
  행동  Interpreter에서 이번 세션 로그 표시
  기대  SID/서비스/필드 표시, 오류 줄 분리, 앱 유지

AC-UC-06-OK  Unlock 성공
  시작  DEFAULT_LOCKED, profile 선택됨, SUCCESS flow
  행동  Extended Apply + 올바른 demo 비밀번호
  기대  EXTENDED_UNLOCKED, Read/Write 탭 사용 가능,
        로그에 10 03…67 02, seed/key 평문 없음

AC-UC-06-NG  Unlock 실패 (현재 Apply 경로)
  시작  동일
  행동  Extended Apply + 잘못된 비밀번호
  기대  7F 27 35, 상태 DEFAULT_LOCKED(롤백), 10 01 복귀 로그,
        keep-alive 중지, Read/Write ACCESS_DENIED
  ※ requirements.xlsx UC-06 실패열의 「EXTENDED_LOCKED 유지」는
     단계별 fixture(ACCESS-INVALID-KEY) 기준. GUI Apply는 교육상 Default 롤백.

AC-UC-02  급정지 Read→AI
  시작  Flipsky EXTENDED_UNLOCKED
  행동  RD-VESC-001(0x1001) Read 후 AI
  기대  50.0 V · ABNORMAL + AI 설명, 근거 ID 존재

AC-UC-05  Write
  시작  unlock 완료
  행동  writable DID에 유효 값 Write
  기대  ACCEPTED(또는 fixture 상태), JSONL/live 기록, 실차 변경 없음

AC-DOD-15  Guard
  시작  DEFAULT_LOCKED
  행동  Read 또는 Write 실행
  기대  ACCESS_DENIED, requests.jsonl에 해당 요청 0건

AC-DOD-16  민감정보
  시작  Unlock 성공 직후
  행동  live_session.log · .session JSONL · AI 컨텍스트 검사
  기대  password·raw seed/key 바이트열 0건 (<REDACTED> 또는 0 패딩 CSV)

AC-DOD-09  장비 없는 시연
  시작  TEST=TRUE, run.bat
  행동  S1~S4 순서 실행
  기대  하드웨어 없이 완주
