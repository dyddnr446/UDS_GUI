3. 수동 테스트 시나리오
--------------------------------------------------------------------------------
열: ID | 사전조건 | 절차 | 기대 결과 | 관련

TS-01  Interpreter live 로그
  사전  run.bat, TEST=TRUE
  절차  ECU 선택 → Extended Apply(정상 PW) → Interpreter 탭
  기대  표에 10/50/27/67 행. output/live_session.log 동일 계열 HEX.
        「로그 지우기」 후 표·파일 헤더만 남음.
  관련  UC-01, FR-08, AC-UC-01

TS-02  Extended + Unlock 성공
  사전  DEFAULT, SUCCESS flow (UI는 SUCCESS 선호)
  절차  Extended Session → Apply → 올바른 비밀번호
  기대  상태 EXTENDED_UNLOCKED, Read/Write 활성,
        로그 10 03…67 02, 이후 주기적 3E 80(Verbose에서 확인)
  관련  UC-06, AC-UC-06-OK, DOD-14

TS-03  비밀번호 실패 → Default 롤백
  사전  DEFAULT
  절차  Extended Apply → 틀린 비밀번호
  기대  경고 INVALID_KEY, Session 콤보 Default,
        상태 DEFAULT_LOCKED, 로그에 7F 27 35 및 10 01/50 01,
        3E keep-alive 중지, Read 시 ACCESS_DENIED
  관련  AC-UC-06-NG, FR-24, FR-26

TS-04  Default Session Apply
  사전  TS-02로 Extended unlock 상태
  절차  Session Control = Default → Apply
  기대  DEFAULT_LOCKED, live 로그 10 01 / 50 01, 3E 송신 중단
  관련  FR-23 대칭(defaultSession), DEVDOC_02 §6

TS-05  Read/Write Guard vs 정상
  사전A DEFAULT_LOCKED
  절차A ReadData 또는 WriteData 실행
  기대A ACCESS_DENIED, .session/requests.jsonl에 신규 요청 없음
  사전B TS-02 unlock
  절차B Read: Flipsky · RD-VESC-001(0x1001)
        Write: 지원 DID에 유효 값 (예 WD-VESC-*)
  기대B Read 50.0 V·ABNORMAL 등 fixture 기대값
        Write ACCEPTED 등 expected_status, live/JSONL 증가
  관련  UC-02/05, DOD-15, FR-14~16, FR-21

TS-06  TesterPresent · Log level
  사전  TS-02 unlock, 약 5초 대기
  절차  Interpreter Log level = Verbose → Normal
  기대  Verbose: 3E 80 REQ 다수 표시
        Normal: 3E 행 숨김, Access/Read 행은 유지
  관련  DEVDOC_02 §6, NFR-03(가독성)

TS-07  AI Advisor 민감정보·degrade
  사전  unlock + Read 1회 이상, .env에 API 키(또는 의도적 실패)
  절차  현상 입력 → AI 실행 / API 키 비워 degrade
  기대  성공: 설명·체크리스트, 사실 Finding과 분리
        실패: 결정론적 결과 유지 + 경고
        컨텍스트·화면에 password·seed·key 평문 없음
  관련  FR-09/12/17, DOD-07/16, NFR-12/18
