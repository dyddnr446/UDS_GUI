================================================================================
UDS Diagnostic GUI — 튜토리얼 / 카탈로그 읽는 법
================================================================================
런타임 SSOT는 catalog/ 엑셀 2개뿐입니다.
  · uds_did_dtc_catalog.xlsx … DID·DTC·프로필·증상(reason_ko 포함)
  · uds_sid_catalog.xlsx ……… Services·SubFunctions·NRC
사람용 설명은 이 파일(및 README.txt)에 둡니다. (구 uds_guide_catalog.xlsx 대체)


--------------------------------------------------------------------------------
1. 데모 한 바퀴 (요약)
--------------------------------------------------------------------------------
  1) run.bat
  2) Target ECU 선택 → Extended Session → Apply → 비밀번호(예: 1234)
  3) EXTENDED_UNLOCKED 확인
  4) ReadData / WriteData / DTC / Interpreter / AI Advisor


--------------------------------------------------------------------------------
2. 카탈로그 시트 역할
--------------------------------------------------------------------------------
[DID/DTC]
  ControllerProfiles   대상 ECU 프로필
  OemExtensions        DID 스키마(data_type, scale, unit, normal_*)
  DidProfileSupport    프로필별 Read/Write·runtime_enabled
  SymptomDidMap        증상 키워드 → DID 후보 (+ reason_ko)
  DTCStatusBits        0x19 상태 바이트 bit0~7

[SID]
  Services             SID 이름·긍정응답 SID·서브펑션 여부
  SubFunctions         parent_sid + sub_function
  NRC                  부정응답 코드


--------------------------------------------------------------------------------
3. HEX 로그 해석 순서 (Interpreter)
--------------------------------------------------------------------------------
  1) 첫 바이트 7F → 요청 SID + NRC
  2) 아니면 Services에서 SID(긍정응답이면 SID−0x40) 조회
  3) 서브펑션 있으면 SubFunctions 조회
  4) 0x19 상태 바이트는 DTCStatusBits
  5) DID 물리값은 OemExtensions scale/unit


--------------------------------------------------------------------------------
4. 대표 SID (교육용 한 줄)
--------------------------------------------------------------------------------
  0x10  진단 세션 변경
  0x27  시드/키 보안 잠금 해제
  0x3E  TesterPresent (세션 유지)
  0x22  DID 읽기
  0x2E  DID 쓰기
  0x19  DTC 읽기 (Sub-Function 0x02/0x01 · Status Mask)
  0x14  DTC 지우기 (확인 다이얼로그)


--------------------------------------------------------------------------------
5. 주의
--------------------------------------------------------------------------------
  · 교육용 요약이며 ISO/OEM 원문 대체가 아닙니다.
  · Live CAN·ISO-TP는 Phase2 Could입니다.
  · 0x27 seed/key는 GUI·로그·AI 경로에 평문으로 남지 않습니다.
